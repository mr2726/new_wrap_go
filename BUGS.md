# Список багов

### 1 баг с регистрацией (DONE)
> Во время регистрации нужно что бы Company Info Form (файл `CompanyInfoForm.js`) открывалась только после дого когда пользователь проходит по ссылке которую отправил supabase на указаную почту и только после заполнения этой формы данные записывались в supabase

### 2 баг с Reset Password (DONE)
> Проблема заключаеться в том что когда пользователь пытаеться сменить пароль, указывает свою почту и получает ссылку для смены пароля. Переходя по ссылке у пользователя открываетья landing page а должно открываться `ResetPassword.js` 

### 3 Баг с форвардом на страницу fleet (папка `Fleet`)
> Суть проблемы в том что Fleet после регистрации должны заходить через обычную страницу login то есть код должен понимать в какой таблице есть запись о аккаунте profiles, fleets или drivers при этом если запись есть в drivers нужно что бы открывалась страница с прозьбой скачать приложение

### 4 баг с неотображением email (DONE)
> Email должен отображаться на страницах `CompanyInfoForm.js` и `confirmEmail.js`
