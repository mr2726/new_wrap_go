## 📊 Breakpoints

### Основные точки останова
```
Desktop:      1024px и выше  (2-4 колонки)
Tablet:       768px - 1024px (1-2 колонки)
Mobile:       480px - 768px  (1 колонка)
Small Mobile: 360px - 480px  (1 колонка, сжато)
```

### Как использовать в CSS
```css
@media (max-width: 1024px) {
  /* Стили для планшетов */
}

@media (max-width: 768px) {
  /* Стили для мобильных */
}

@media (max-width: 480px) {
  /* Стили для маленьких телефонов */
}
```

## 💡 Советы и трюки

### 1. Использование `clamp()`
```css
/* Автоматически масштабируется между min и max */
font-size: clamp(1.2em, 3vw, 2em);
padding: clamp(1em, 2vw, 2em);

/* Значение: min, preferred, max */
```

### 2. Мобильная оптимизация
```css
/* Используйте mobile-first (от маленького к большому) */
.element {
  width: 100%;  /* Мобильный по умолчанию */
}

@media (min-width: 768px) {
  .element {
    width: 50%;  /* Планшет и выше */
  }
}
```

### 3. Гибкие сетки
```css
/* Автоматически подстраивается к ширине */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
```

### 4. Скрытие элементов
```css
/* Скрыть на мобильных */
@media (max-width: 768px) {
  .desktop-only {
    display: none;
  }
}

/* Показать только на мобильных */
@media (max-width: 768px) {
  .mobile-only {
    display: block;
  }
}
```

## 🚨 Часто встречаемые проблемы

### Проблема: Меню не открывается
**Решение:** Проверьте, что в SideBar.js включены все импорты
```jsx
import { MdMenu, MdClose } from 'react-icons/md';
```

### Проблема: Текст слишком маленький
**Решение:** Используйте `clamp()` с правильными значениями
```css
font-size: clamp(1em, 2vw, 1.6em); /* Минимум 1em */
```

### Проблема: Таблица не вмещается
**Решение:** Добавьте `data-label` и используйте мобильные стили
```jsx
<td data-label="Название">{value}</td>
```

### Проблема: Горизонтальный скролл
**Решение:** Проверьте `max-width: 100%` и `overflow: auto`
```css
.element {
  max-width: 100%;
  overflow-x: auto;
}
```
