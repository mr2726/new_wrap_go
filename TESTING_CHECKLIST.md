# ✅ Чек-лист адаптивности

Используйте этот чек-лист для проверки адаптивности нового функционала или компонентов.

## 📋 Перед запуском на production

### Общие требования
- [ ] Все страницы тестированы на мобильных (360px, 480px)
- [ ] Все страницы тестированы на планшетах (768px, 1024px)
- [ ] Все страницы тестированы на ПК (1440px+)
- [ ] Боковое меню открывается/закрывается корректно
- [ ] Оверлей появляется при открытии мобильного меню

- [ ] Меню закрывается при выборе пункта
- [ ] Нет горизонтального скролла на мобильных

- [ ] Line-height адаптивен и достаточен

- [ ] Достаточный отступ между кнопками (минимум 0.5em)
- [ ] Hover эффекты работают на всех устройствах
- [ ] Активные состояния хорошо видны

### Формы
- [ ] Все input элементы полной ширины на мобильных
- [ ] Labels читаемы и над input'ами
- [ ] Input фокусировка хорошо видна
- [ ] Ошибки/валидация сообщения четкие
- [ ] Кнопка submit полной ширины на мобильных

### Таблицы
- [ ] Таблицы не переполняют контейнер
- [ ] На мобильных используется карточный вид
- [ ] Все columns имеют `data-label` атрибут
- [ ] Мобильная таблица правильно отображает данные

### Изображения

### Производительность
- [ ] Нет лишних media queries
- [ ] CSS файл минимизирован

### Навигация

- [ ] Иконки видны и правильно масштабируются

### Сетки иLayoutы

- [ ] 2 колонки на планшете

- [ ] Нет пустого пространства

### Модальные окна
- [ ] Модальное окно центрировано на всех экранах
- [ ] Размер модального окна адаптивен

## 🧪 Инструменты для тестирования

### Chrome DevTools (рекомендуется)
```
1. Откройте DevTools: F12
2. Нажмите: Ctrl+Shift+M (Cmd+Shift+M на Mac)
3. Выберите устройство из выпадающего меню
4. Протестируйте все страницы
```

### Firefox Developer Tools
```
1. Откройте DevTools: F12
2. Нажмите: Ctrl+Shift+M
3. Измените размер экрана вручную
4. Проверьте консоль на ошибки
```

### Реальные устройства
```
1. Откройте на реальном телефоне
2. Используйте http://your-ip:3000 (localhost не работает)
3. Протестируйте в обоих ориентациях (portrait и landscape)
4. Проверьте touch взаимодействие
```

## 🔍 Примеры правильной адаптивности

### ✅ Правильно
```css
/* Масштабируемый шрифт */
font-size: clamp(1.5em, 4vw, 2.5em);

/* Масштабируемый padding */
padding: clamp(1em, 2vw, 2em);

/* Адаптивная сетка */
.grid {
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}

/* Медиа-запрос */
@media (max-width: 768px) {
  .element {
    width: 100%;
  }
}

/* Мобильное меню */
@media (max-width: 768px) {
  .menu {
    position: fixed;
    left: -100%;
    transition: left 0.3s ease;
  }
  
  .menu.open {
    left: 0;
  }
}
```

### ❌ Неправильно
```css
/* Жесткий шрифт */
font-size: 16px;

/* Жесткий padding */
padding: 2em;

/* Жесткие размеры */
width: 500px;
height: 600px;

/* Нет медиа-запросов */
.element {
  width: 50%;
}

/* Переполнение на мобильных */
overflow: visible;
```

## 📝 Коммент-гайдлайн для кода

При добавлении адаптивных стилей используйте комменты:

```css
/* ╔═════════════════════════════════════ */
/* ║ АДАПТИВНЫЙ ДИЗАЙН - 768px и ниже   */
/* ╚═════════════════════════════════════ */
@media (max-width: 768px) {
  .sidebar {
    /* Боковое меню скрывается и появляется по кнопке */
    position: fixed;
    left: -100%;
    transition: left 0.3s ease;
  }

  .sidebar.open {
    left: 0;
  }
}
```
